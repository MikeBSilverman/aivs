# aivs-client

Reference client for AIVS member firms — an importable Python SDK and the `aivs`
command-line tool.

```console
$ aivs enroll meridian-global --out ~/.config/aivs   # generate a key + CSR locally
$ aivs poll                                         # every collection, STIX NDJSON on stdout
$ aivs submit finding.json --title "Prompt injection in agent runtime" --scope ai_system
$ aivs ack 0f9c... --type actioned
```

`aivs poll` writes newline-delimited STIX objects to stdout and keeps its own
cursor per collection, so piping it into a SIEM or TIP ingest is a one-liner and
re-running it never re-delivers content you already have.

The private key generated by `aivs enroll` never leaves the machine; only the
certificate signing request is sent to the hosting ISAC.

The client does not depend on `aivs-schemas`: it sends plain JSON, and the
server's request models decide what is valid, so a value the client has never
heard of is refused by the server rather than by a stale copy of its rules.
